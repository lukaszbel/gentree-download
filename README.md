# Gentree – pobieranie

Najnowsza wersja: **v0.32** – [Gentree-Setup.exe](https://github.com/lukaszbel/gentree-download/raw/main/Gentree-Setup.exe) (instalator, Windows 10/11).

Za darmo do 200 osób (łącznie we wszystkich drzewach; większe drzewo wczytasz do podglądu). Z licencją: do 2000 osób albo bez limitu oraz połączenie z Claude. Demo i kontakt: https://lukasz.beluch.pl/gentree

**Gentree i Claude:** z licencją połączysz program z aplikacją Claude (Claude Desktop, Claude Code) – Claude odpowie na pytania o drzewo i na Twoją prośbę dopisze osoby i fakty. [Instrukcja](GENTREE-I-CLAUDE.md)

Instalator nie wymaga uprawnień administratora. Windows może pokazać ostrzeżenie SmartScreen – kliknij „Więcej informacji” → „Uruchom mimo to”.

Korzystanie z programu wymaga akceptacji [umowy licencyjnej](UMOWA-LICENCYJNA.md) (program pokazuje ją przy pierwszym uruchomieniu).

Znalazłeś błąd albo masz pomysł? [Zgłoś go tutaj](https://github.com/lukaszbel/gentree-download/issues/new/choose) (wymaga konta GitHub; zgłoszenia są publiczne – bez danych osób żyjących).

### Co nowego w v0.32 (17.10.2026)

- **Zdjęcie czy dokument.** W oknie materiału oznaczysz skan aktu, list czy inny dokument przyciskiem **„📄 To dokument (skan)”** (i z powrotem „🖼 To jednak zdjęcie”). Dokumenty mają na kafelkach znaczek 📄, a w Archiwum zdjęć są osobno od fotografii. Materiały oznaczone tak w Ancestry są rozpoznawane same.
- **Poprawka: program pamięta motyw.** Wybrany jasny lub ciemny wygląd (przycisk ◐) zostaje po ponownym uruchomieniu programu.
